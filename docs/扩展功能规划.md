# 扩展功能规划

本文档记录 PcRemoteController 的后续扩展方向，按“交互桌面操作 / 系统便捷命令 / 协议与可靠性 / 暂不建议”分类。优先级为建议排序，不代表承诺。

## 已完成（本批）

### A1 输入文字 / 粘贴文字 / 复制文字

- 命令：`输入文字 <文本>`、`粘贴文字 <文本>`、`复制文字 <文本>`
- 实现：`TextController`（前缀匹配，位于控制器列表最前）→ Agent `input.text` / `input.paste` / `input.copy`（Base64 UTF-8）
- `输入文字`：Unicode SendInput 逐字符输入；`\n` / `\r` 转为 Enter，`\t` 转为 Tab
- `粘贴文字`：写入剪贴板后发送 Ctrl+V；会覆盖原剪贴板内容
- `复制文字`：只写入剪贴板，不发送 Ctrl+V；成功后由 Agent 的 `DesktopNotify` 在右下角显示自绘浮层“文字已复制到剪贴板（N 个字符）”
- 复制通知：
  - 自绘 topmost 分层窗口（GDI）+ 独立线程 + 3.5 秒淡入/淡出定时器，异步、best-effort
  - 不依赖 `Shell_NotifyIcon`、AUMID 或开始菜单快捷方式，不会出现系统 Toast 的默认感叹号
  - 通知失败不影响复制结果；全屏独占应用可能遮挡浮层；不进入系统通知中心
  - 通知内容不包含文本
- 限制：
  - 输入到当前前台窗口，焦点不对会输入到别处
  - Agent 非提权，无法向管理员权限窗口输入（UIPI）
  - 命令行本身是 GBK，emoji 等 GBK 不可表示的字符无法通过中文命令传入；后续可增加 ASCII base64 模式
  - 单次最多 20000 个 UTF-16 单元；Agent 报文上限 256 KB
  - 日志只记录模式和字符数，不记录文本内容
  - 文本通过命令行参数传入，本机同一用户下的其他进程可能读取命令行；不要用它传输高敏感凭证。后续可考虑 stdin/文件输入或 C14 管道令牌

## A. 交互桌面操作（必须走 Agent）

### A2 打开程序 / 网址 / 文件夹

- 命令：`打开程序 notepad`、`打开网址 https://...`、`打开文件夹 D:\Downloads`
- Agent 在交互会话调用 `ShellExecuteW`；session 0 的 `start` 不会显示在用户桌面
- 注意校验路径/URL，不要默认提权启动
- 工作量：小

### A3 重启资源管理器

- 命令：`重启资源管理器`
- Agent 结束本会话的 `explorer.exe` 后重新启动；桌面会短暂闪动
- 用途：任务栏消失、桌面卡死时远程恢复
- 工作量：小

### A4 窗口查询与控制

- 命令：`窗口列表`、`切换窗口 <关键词>`、`关闭窗口`
- Agent 使用 `EnumWindows` / `GetWindowText` / `SetForegroundWindow`；关闭用 `PostMessage(WM_CLOSE)`
- 依赖 C13 的多行响应
- 工作量：中

### A5 桌面通知 / 朗读

- 命令：`通知 <文本>`、`朗读 <文本>`
- Agent 发送 Toast（WinRT）或使用 SAPI `ISpVoice`
- 用途：提醒电脑前的人，例如“还有 10 分钟重启”
- 工作量：小到中

### A6 截图到剪贴板

- 命令：`截图到剪贴板`
- 在截图功能之上，用 GDI 截屏后写 `CF_DIB` 到剪贴板
- 依赖：先有截图功能
- 工作量：小

## B. 系统便捷命令（CLI，session 0 可完成）

### B7 `--doctor` 自检

- 一条命令检查：是否提权、Agent 任务/管道是否正常、键盘恢复任务是否存在、`keyboard_targets.txt` 与设备是否匹配、音频端点、日志是否可写
- 逐项输出 `OK` / `FAIL`，有问题时退出码非 0
- 工作量：小到中；优先推荐

### B8 电源计划切换

- 命令：`电源计划 高性能` / `电源计划 平衡` / `电源计划 节能`
- CLI 调用 `powercfg /setactive` 三个固定 GUID
- 工作量：小

### B9 网络状态 / 刷新 DNS

- 命令：`网络状态`、`刷新DNS`
- 状态包含适配器、IPv4、网关、DNS、Wi-Fi SSID、链路速度；刷新 DNS 用 `DnsFlushResolverCache`
- 不建议做“禁用/重启网卡”，容易切断自己的 SSH 连接
- 工作量：小

### B10 进程查询 / 结束

- 命令：`进程列表 [关键字]`、`结束进程 <名称>`
- CLI 使用 `Toolhelp32Snapshot` 枚举；结束进程必须严格匹配名称并拒绝系统关键进程
- SSH 本身可完成，但单命令封装更适合手机端/脚本
- 工作量：小到中

### B11 显示模式 / 亮度（P2）

- 命令：`投影模式 复制/扩展/仅电脑`、`亮度 50`
- `DisplaySwitch.exe` 或 `SetDisplayConfig` 修改投影模式；亮度依赖 WMI，笔记本才可靠
- 工作量：中，硬件相关

## C. 协议与可靠性

### C12 Agent 版本握手

- `ping` 返回协议版本/构建号；`AgentClient` 发现版本过旧时自动重启 Agent
- 否则新增 Agent 命令后，旧常驻进程会一直返回 `404`
- 工作量：小

### C13 多行 / JSON 响应

- 现状只有单行 `OK` / `ERR`；窗口列表、剪贴板、状态查询需要多行或 `OK <长度>\n<payload>`，也可以直接 JSON
- 与 C12 一起做更稳
- 工作量：中

### C14 管道访问令牌

- 加入文字输入/剪贴板能力后，命名管道更敏感；当前 DACL 只按用户隔离，同一用户下的其他进程也能连接
- 在 `PCR1` 握手中加入仅当前用户可读的随机令牌
- 工作量：中

## D. 暂不建议

- **自动解锁 / 注入登录密码**：凭证安全风险远大于便利性
- **通用按键注入 / 任意命令执行**：SSH 本来就有 shell，开放通用注入只会扩大攻击面
- **禁用网卡 / 禁用鼠标**：前者可能断掉 SSH 生命线，后者和键盘一样有锁死风险
- **蓝牙控制**：项目已明确移除，不要回退

## E. 更早讨论过的功能（未在本批实施）

- 电源族：关机 / 重启 / 取消关机 / 定时关机 / 睡眠 / 注销
- 媒体扩展：上一首 / 下一首 / 停止 / 静音 / 麦克风静音
- 截图（全屏 / 窗口），可延伸到 A6
- 锁定电脑
- 状态查询（开机时长 / 电量 / 内存 / 磁盘 / IP / 会话 / Agent）
- 关闭显示器
- 剪贴板桥接：A1 的 `粘贴文字` 已覆盖“设置并粘贴”用例，读取剪贴板仍待做
- 鼠标禁用
- 保持唤醒
- 定时截图 / 截图到剪贴板

## 建议顺序

1. `--doctor` + 打开程序/网址/文件夹 + 重启资源管理器（低风险、当天可验证）
2. 窗口列表（先做 C13 响应扩展）、通知/朗读
3. 电源族与媒体扩展
4. 截图 / 锁定 / 状态查询
5. 音频输出切换、显示设置等硬件相关项
